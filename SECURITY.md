# Security

This repository contains the MIT-licensed local stdio bridge and client integration metadata for BlockVectra MCP. The hosted MCP service is operated by BlockVectra.

If you think you have found a vulnerability in this repository or in the hosted MCP service, email blockvectra@gmail.com. Please do not post vulnerability details in public issues or discussions.

A useful report includes:

- The affected component and the version or commit
- Steps to reproduce
- Expected and actual behavior, and the impact you see

Redact sensitive data before sending. Never include API keys, private keys, or seed phrases.
